# SCARE-GUARD LAB
偽クリーナー警告・スケアウェア検知・啓発シミュレーター

Webブラウザ閲覧中やアプリ利用中に突然「ウイルスが検出されました」「今すぐクリーナーをインストールしてください」と不安を煽る手口（スケアウェア / 偽警告広告）を安全に学び、見分けるための体験型サイバーセキュリティ教育サイトです。

---

## 🌟 主な機能・特徴

1. **手口シミュレーター**
   - 典型的な偽クリーナー警告画面（感染カウントダウン、偽システムスキャン、端末情報の表示）の再現
   - 「X線・手口解説モード」と「実際の表示モード」の切り替え
   - 警告音（Web Audio API）やスマホの振動（Vibration API）のからくり体験
   - Web閲覧時（ブラウザ型）と無料アプリ利用時（オーバーレイ型）の2つのシナリオ

2. **防護アプリ開発（3大方式の解説とインタラクティブデモ）**
   - 方式①：ローカルVPN DNSフィルタリング方式
   - 方式②：ブラウザ拡張機能（コンテンツブロッカー）方式
   - 方式③：常駐監視・インストール検知方式（Android向け）
   - 模擬コンソールでのブロック・駆除シミュレーション体験

3. **詐欺URL判定診断ツール**
   - 入力されたURLの危険度（0〜100点）をリアルタイム判定
   - 不審なトップレベルドメイン（TLD）、偽ブランド文字列、偽装パス、カウントダウンパラメータの検知

4. **技術的からくり（Technical Anatomy）**
   - なぜブラウザから端末内部のウイルスを検知できないのか（ブラウザのサンドボックス構造）
   - 機種名や画面サイズがバレている理由（User-Agent）
   - プッシュ通知スパムやカレンダースパムの仕組み

5. **なぜ普通のサイトやYouTubeに詐欺広告が出るのか？（Ad Ecosystem & Malvertising）**
   - アドネットワークとリアルタイム入札（RTB）による自動配信の仕組み
   - 審査ロボットと一般ユーザーで表示をすり替える「クローキング技術」
   - 詐欺業者の利益構造（高額サブスク課金、アフィリエイト報酬）
   - プラットフォームの現状と利用者ができる自衛策

6. **正しい対処手順ガイド**
   - 遭遇時の3ステップ（画面内は触らない、タブごと閉じる、タスクキル）
   - 万が一クリック・インストール・課金してしまった場合の復旧FAQ

## 🚀 ローカルでの起動方法

Windows PowerShellで以下のコマンドを実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

ブラウザで以下のURLを開きます：
```
http://localhost:5500/
```
